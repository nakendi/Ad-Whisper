# 🎙️ AdWhisper — AI TikTok Audio Ad Detector (@twitch.clown)

Автономный локальный инструмент на Python для автоматического сбора, фильтрации и глубокого поиска рекламных интеграций в TikTok-видео аккаунта **@twitch.clown** с использованием локальных нейросетей **OpenAI Whisper** (через faster-whisper на GPU CUDA) и **Meta Demucs** (разделение вокала и музыки).

---

## 📋 Целевые рекламные фразы

Система обучена и настроена на обнаружение трёх конкретных рекламных конструкций с учётом искажений Whisper, оговорок стримера, перестановок слов, сленга и фоновой музыки:

1. **Вариант №1:**
   > *«А улучшить своё яйцо ты можешь в баттлпассе Caser»*
   - Допускаются вариации: Caser/кейсер/кейсера, батлпас/баттлпасс/battlepass, отсутствие служебных слов, фонетические искажения.
2. **Вариант №2:**
   > *«А улучшить свои скины ты можешь на Upgrader»*
   - Допускаются: Upgrader/апгрейд/апгрейдере, перестановка слов («свои скины ты можешь улучшить на Upgrader»), пропуск слова «свои», сленговые формы.
3. **Вариант №3:**
   > *«А улучшить рарки на подарки ты можешь на DotaGrade»*
   - Допускаются: *DotaGrade, Dota dotagrade, Dota Grade, Dota Upgrade, дотадотагрейд, дота грейд*, ошибки распознавания английских названий.

> **Защита от ложных срабатываний:**
> Одиночные случайные упоминания слов («яйцо», «скины», «дота») в бытовых разговорах **не засчитываются** как совпадение. Алгоритм требует выявления всей связки: **[Действие: улучшить] + [Объект: яйцо / скины / рарки на подарки] + [Площадка: Caser / Upgrader / DotaGrade]**.

## ⚡ Оптимизация под оборудование

Проект полностью оптимизирован под конфигурацию:
- **GPU:** NVIDIA GeForce RTX 4070 12 GB GDDR6X (CUDA, вычисления `float16`, VRAM ~3.8–5.2 GB).
- **CPU:** Intel Core i5-14600KF (многопоточная предобработка аудиопотоков).
- **RAM:** 32 GB DDR5.
- **Хранилище:** Локальная СУБД SQLite для кэширования истории и предотвращения повторной обработки.

## 🚀 Установка и запуск

Проект предоставляет 2 удобных варианта запуска:

### Вариант 1: Запуск через Desktop EXE (без всплывающего окна CMD)
Дважды кликните по:
```
AdWhisper.exe
```
- Запускается бесшумно в фоновом режиме (никаких консольных черных окон CMD не выскакивает).
- Открывает интерфейс в отдельном нативном окне приложения.
- При закрытии окна приложения фоновые процессы корректно завершают работу.

---

### Вариант 2: Запуск через командный файл (run.bat)
Дважды кликните по:
```batch
run.bat
```
- Проверяет установку Python 3 в системе.
- Если виртуальное окружение `.venv` отсутствует (например, после свежего `git clone`), скрипт автоматически создаст `.venv` и установит все библиотеки из `requirements.txt`.
- Автоматически освобождает порт 8501 (или динамически выбирает следующий свободный порт при конфликтах сокетов).
- Запускает сервер и открывает веб-интерфейс в браузере с отображением журнала в окне консоли.

## 🔍 Ключевые возможности

### 1. Фильтр публикаций по датам (Раздел 10 ТЗ)
- Поля **«Дата начала»** и **«Дата окончания»** (включительно).
- Фильтрация происходит по **дате загрузки** (`upload_date` / `timestamp`), а не обновления.
- Граничные даты учитывают время `00:00:00` начала и `23:59:59` окончания.
- Кнопка **«За всё время»** для полного сканирования.
- Валидация: если дата начала позже окончания, интерфейс выдает предупреждение и блокирует запуск.
- Фильтр применяется **до скачивания аудио**, экономя трафик и вычислительные ресурсы GPU.

### 2. Фильтр по просмотрам
- Видео с количеством просмотров `<= 2000` отсеиваются на этапе чтения метаданных.
- Только публикации со **строго больше 2000 просмотров** поступают на обработку.

### 3. Распознавание речи (faster-whisper large-v3)
- Работает на видеокарте RTX 4070 через `faster-whisper` (`compute_type="float16"`).
- Специфический `initial_prompt` с именами брендов и сленгом стримеров.
- VAD (Voice Activity Detection) настроен с щадящим порогом `0.32` и паддингом `400мс`, чтобы не терять тихую речь.

### 4. Отделение вокала через Demucs
- При наличии сомнений (уверенность распознавания 45–74%) или по кнопке в интерфейсе вызывается **Meta Demucs (htdemucs)**.
- Demucs изолирует дорожку вокала, устраняя громкую фоновую музыку, басы и звуковые эффекты игры.
- Транскрипция изолированного вокала сравнивается с исходной дорожкой для принятия итогового решения.

### 5. Обход сетевых ограничений TikTok (Без нарушения правил)
В строгом соответствии с требованием *«Не обходить CAPTCHA, авторизацию и технические ограничения TikTok»*:
- Если TikTok активирует экран защиты WAF (Slardar/Cloudflare), приложение вежливо уведомляет пользователя и предлагает:
  1. Вставить список ссылок на видео напрямую.
  2. Загрузить стандартный файл `cookies.txt` из браузера.
  3. Загрузить уже сохранённые локальные аудиофайлы для пакетного анализа без сети.

### 6. Экспорт результатов
- **Excel (.xlsx):**
  - Лист 1: Сводка сканирования и статистика.
  - Лист 2: Все найденные рекламные совпадения с кликабельными гиперссылками на TikTok.
  - Листы 3–5: Разделение по вариантам №1, №2, №3.
  - Лист 6: Видео без рекламы.
  - Лист 7: Видео с недостаточным качеством звука / ошибками.
- **CSV (.csv):**
  - Таблица с кодировкой UTF-8 BOM (`utf-8-sig`) для корректного открытия в русском Microsoft Excel.

## 🧪 Запуск тестов

Для проверки работоспособности всех модулей выполните:
```powershell
.\.venv\Scripts\python -m unittest discover -s tests
```
Все 21 тест проверяют распознавание вариантов, отсечение ложных упоминаний, дедупликацию в SQLite, фильтрацию дат и безопасное HTML/XSS-экранирование.
